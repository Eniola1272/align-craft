# Align Craft

A responsive, buildless agency website with Home, Pricing and About pages. Built with semantic HTML, CSS and vanilla JavaScript.

## Preview

Run `python3 -m http.server 4173 --directory dist`, then open http://localhost:4173.

## Structure

- `dist/app.js`: shared components, page content and interactions
- `dist/styles.css`: lavender / obsidian design system and responsive layouts
- `dist/assets/creation.png`: original generated hero artwork
- `dist/pricing/index.html`, `dist/about/index.html`: route entry points

## Before public launch

The enquiry flow prepares an email addressed to contact@aligncraft.com.ng and offers a copyable summary. Sending happens in the visitor's email app. Project examples are explicitly labelled concepts. No client testimonials, project outcome metrics or team identities have been invented.

The collaboration photograph is loaded from Unsplash. Inter is loaded from Google Fonts. All other artwork and interface elements are local.
